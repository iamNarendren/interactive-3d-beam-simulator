# Structural ROM Lab
**Project topic:** Physics-Guided Reduced-Order Machine Learning for Fast Structural Deformation Prediction

A static browser app that compares a **finite-element (FEM) reference solution** with a **trained reduced-order ML model (ROM)** for a cantilever beam with a moving point load and a local stiffness loss.

## Run locally
Open a terminal in the folder containing `index.html` and run:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`. (ES modules and the three.js CDN need a web server, not `file://`, and an internet connection for three.js.)

## What is in the folder
| File | Purpose |
|---|---|
| `index.html`, `styles.css`, `app.js` | Interface, 3D scene, plots, metrics |
| `fem.js` | Euler–Bernoulli beam FEM (48 elements) — the reference solver |
| `rom.js` | In-browser inference of the trained model |
| `rom_model.js` | Trained weights + held-out test metrics (generated by `train_rom.py`) |
| `train_rom.py` | Full training pipeline: FEM snapshots → POD → neural network → held-out evaluation |
| `rom_validation.json` | Train / validation / test metrics from the last training run |
| `tests/verify_js.mjs` | `node tests/verify_js.mjs` — checks FEM vs analytical solution and browser ROM vs FEM |

## The trained model
- **Data:** 8,192 FEM training snapshots (load position, weak-zone centre, stiffness loss; Sobol sampling, denser near the support), plus 512 validation and 1,024 **held-out test** snapshots from independent sequences.
- **Physics-guided normalisation:** for a linear-elastic beam, deflection scales exactly with `P / (E·I)`. The model is trained on the dimensionless response `u·E·I/(P·L³)`; load and material (Steel / Iron / Tungsten) are applied analytically. The network learns the dependence on load position, weak-zone location/extent and stiffness loss.
- **Reduced representation:** each snapshot = unit-norm shape (compressed with POD/SVD to 10 modes) × amplitude.
- **Network:** MLP 5-96-96-11 with tanh (10,955 parameters), trained with L-BFGS (scikit-learn). Inputs: `[x_load, ln x_load, weak-zone start, weak-zone end, stiffness loss]`.
- **Inference** runs in the browser (`rom.js`), no server needed.

### Held-out test results (1,024 unseen FEM cases)
| Metric | Mean | Median | 95th pct | Worst |
|---|---|---|---|---|
| Relative L2 error | 0.51 % | 0.41 % | 1.35 % | 3.95 % |
| RMSE (steel, 12 kN) | 0.018 mm | | | 0.39 mm |
| Max point error (steel, 12 kN) | 0.036 mm | | | 0.76 mm |

Context: a cubic-polynomial ridge baseline on the same inputs gets 1.09 % mean error; predicting the mean snapshot (no learning) gets ≈ 328 %.
Re-run `python train_rom.py` to reproduce (about 3 minutes on a laptop CPU). The browser app shows these numbers and recomputes the error against FEM live for every control change.

## Experiment controls
- **Material:** Steel (200 GPa), Iron (110 GPa), Tungsten (400 GPa).
- **Applied load**, **local stiffness loss**, **weak-section position**, **load position**; **Animate moving load** sweeps the load along the beam.
- Drag the 3D scene to orbit; scroll to zoom.

## Verification done
- FEM tip deflection for a uniform cantilever (12 kN, L = 1 m, E = 200 GPa, I = 1.2e-6 m⁴) = 16.667 mm, equal to the analytical `P L³ / (3 E I)`.
- The JavaScript FEM matches the Python FEM used to generate training data (relative difference ≈ 4e-10).
- On 1,000 fresh random cases, the browser ROM gives 0.50 % mean relative L2 error, consistent with the Python held-out test.

## Limitations (please keep when reporting results)
- Euler–Bernoulli cantilever only: one point load, one rectangular weak zone of fixed width (11 % of the length); no shear deformation, 3D stress or nonlinearity.
- The model is trained only for load position 5–95 %, weak-zone centre 15–85 % and stiffness loss 0–70 % (the slider ranges). Behaviour outside this range was not tested.
- Fixed geometry (48 elements, L = 1 m, I = 1.2e-6 m⁴). Load and Young's modulus are not learned; they rescale the prediction analytically, valid only for linear response.
- Accuracy is not uniform: the worst cases (load very close to the support, tiny deflections) have several times the mean error.
- Errors are relative to this FEM model, not to experiments or a commercial solver.

Educational prototype — not a structural design tool.
