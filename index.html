Each row is rebuilt from the current controls with one change. Load and Young’s modulus rescale the response exactly (displacement ∝ P/EI for a linear-elastic beam), so those rows share the same relative error; the weak-zone and load-position rows exercise what the network actually learned.

LIMITATIONS & FUTURE SCOPE
Current limitations
  • Euler–Bernoulli cantilever only: one point load, one rectangular weak zone of fixed width (11% of the length), no shear deformation, no 3D stress, linear elastic material.
  • Trained only for load position 5–95%, weak-zone centre 15–85% of the length, and local stiffness loss 0–70%. The sliders are locked to this range; behaviour outside it was not tested and should not be trusted.
  • Fixed geometry: 48-element mesh, L = 1 m, I = 1.2×10⁻⁶ m⁴. Load and Young’s modulus are not learned — they rescale the prediction analytically, which only holds while the response stays linear.
  • Accuracy is not uniform: the mean held-out error is small, but the worst cases (load very close to the support, where deflections are tiny) are several times larger.
  • Errors are measured against this FEM model, not against experiments or a commercial solver.
Future scope
  • Add parameters (weak-zone width, several weak zones, section size, distributed and multiple loads) and retrain on a larger snapshot set.
  • Try Gaussian-process or ensemble models to obtain prediction uncertainty, and a physics-informed loss.
  • Generate snapshots from Timoshenko or 3D solid FEM, add material nonlinearity, and run mesh-convergence checks.
  • Validate against experimental or commercial-FEM benchmarks and report speed-ups on full 3D models.
